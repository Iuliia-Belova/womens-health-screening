# Women's Preventive Screening in Europe

## Цель проекта
Проанализировать участие женщин в профилактическом скрининге рака груди и шейки матки в европейских странах.

## Основные вопросы
- Чем Испания отличается от других стран Европы?
- Какие возрастные группы проходят скрининг реже?
- Есть ли различия по уровню образования?
- Как менялись показатели со временем?

## Инструменты
- Python
- Pandas
- SQL
- Power BI
- Git

## Источник данных
Eurostat / European Health Interview Survey
